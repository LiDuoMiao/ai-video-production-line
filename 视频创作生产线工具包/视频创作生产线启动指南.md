# 视频创作生产线启动指南

这是 AI 执行视频创作生产线的入口。收到启动指令后，先通读本指南，了解 01–10 阶段和文档读取顺序。接着执行「启动时怎么做」。运行过程中，只打开当前节点所需的执行标准、题材指南和本期已有产物。

## 默认执行范围

普通启动指令默认执行 **01–10 的完整制作和本地交付**。01 需要收集本期信息并等待用户确认选题。用户确认后，在同一轮内建立工程、完成 01，并按阶段顺序持续执行到 10。

每完成一个阶段，保存并核对本阶段产物。交接条件满足后，立即按下表读取下一阶段执行标准，执行其首个节点。阶段进度可在执行中告知用户，发出进度后接着做。用户明确要求只测某一阶段或指定停止点时，按指定范围结束。

需要用户输入或授权、遇到当前标准规定的阻塞，或完成 10 本地交付时，再结束当前轮并说明情况。用户要求继续时，读取本指南及工程中已有的交接产物，从首个未完成的节点恢复，并沿用本期执行范围。

## 启动时怎么做

1. **定位工具包。** 以本指南所在目录作为工具包根目录。以下标准和题材包路径均相对于这个目录。
2. **索取本期信息。** 按下方「本期信息输入固定格式」向用户索取信息。启动消息里已经给出的信息直接使用，缺少题材或选题时，只补问缺项。目标画幅和成片分辨率优先采用用户给出的值，其次沿用本期适用且已明确的默认值。未能确定的项在 01 完成前补问。
3. **初查并对齐选题。** 收到题材和选题后，进入 01.3。开始查询前，先找到并读取启动阶段执行标准和对应题材的《资料调查指南》。两份文件均可用时，按其要求初查，再按[执行标准中的固定格式](标准文档/01%20启动阶段执行标准.md#选题介绍固定格式)反馈选题介绍，请用户确认。任一文件缺失或不可读，按「必需文件缺失时」处理。有偏差就请用户补充或纠正信息，再初查、再反馈。
4. **确认后先创建本期工程。** 用户确认选题、目标画幅和成片分辨率均已确定后，读取[《视频创作工程目录规范》](标准文档/视频创作工程目录规范.md)。在工具包同级的 `../视频创作/` 下，以确认的选题命名本期工程，并创建 01–10 的阶段目录。根目录尚不存在时先创建。
5. **保存 01 产物并自动继续。** 读取[《选题确认记录编写规范》](文档编写规范/选题确认记录编写规范.md)和[《资料初步调查报告编写规范》](文档编写规范/资料初步调查报告编写规范.md)，将两项产物保存到本期工程的 `01 启动阶段/`，记录采用的题材包、适用版本和目标画幅、成片分辨率及其出处。然后进入 02 环境检查。后续各阶段的过程文档和产物放在本期工程的对应目录。

### 本期信息输入固定格式

启动消息尚未提供题材和选题时，发送以下提示。

```text
请提供本期视频制作信息：

题材：
本期选题：
目标画幅（横屏 16:9、竖屏 9:16 或横竖双版）：
成片分辨率（宽×高，如横屏 1920×1080、竖屏 1080×1920；双版分别填写）：
补充信息（选填，可附文件、链接或背景说明）：
```

## 题材文件调用表

按本期题材定位 `题材包/<题材名>/`。本版随附「案件纪实」题材包，视觉文件位于 `题材包/案件纪实/视觉方案.md`。选用自建题材包时，读取其目录下的同名文件。只读取当前节点适用的章节，后续复查沿用本期采用的版本。

| 节点 | 读取题材包中的文件 | 使用哪部分 |
| --- | --- | --- |
| **01.3 初步资料调查** | `资料调查指南.md` | 选题识别与初查 |
| **03.1–03.2 讲述方案与故事框架** | `故事方案指南.md` | 讲述方案、故事框架 |
| **03.3–03.5 核对资料与深查** | `资料调查指南.md` | 资料充足标准、深查来源与核对方法 |
| **04.1–04.3 故事创作、审稿与修订** | `故事创作指南.md`、`作家提示词.md`、`编辑提示词.md` | 04.1 按作家提示词启动作家，04.2 按编辑提示词另启编辑，04.3 交原作家修订。 |
| **05.1 编写口播稿** | `口播指南.md` | 口播写法 |

| **06.2–06.4 素材制作、检查与返修** | `视觉方案.md` | 素材制作与检查要求 |
| **08.1 检查实际成片** | `视觉方案.md`，按需参照本期采用的口播稿 | 成片视觉检查与需要核对的讲述要求 |

02 按需参考本期已采用的视觉方案。由后续阶段确定的视觉、配音和素材要求，按 02 执行标准记录为「待后续核对」。其他节点使用通用标准与上游交付。用户指定视觉方案时，将采用文件记入本期选题确认记录，05 及下游按该方案执行。

## 必需文件缺失时

执行当前节点前，核对并读取该节点的必需文件。缺失、不可读或规则不明确时，停在当前节点，报告节点编号、具体文件路径和受影响的动作，等待用户确认如何继续。替代做法须由用户明确确认。

例如，01.3 缺少启动阶段执行标准或对应题材的《资料调查指南》时，只报告缺项。该节点的查询、选题介绍和确认请求，在文件补齐或替代做法获得确认后再执行。
