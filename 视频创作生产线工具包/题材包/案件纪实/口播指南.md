# 案件纪实口播指南

用于 05.1，将《故事终稿》转成听起来自然、线索清楚的口播。三列和两个派生文本的格式按[《口播稿编写规范》](../../文档编写规范/口播稿编写规范.md)执行。

1. **开头让观众知道要追踪什么。** 沿用终稿的切入点，用一个具体发现、反常之处或待解释的问题进入。保留理解开头所需的背景，把其他背景放到它真正有用的位置。
2. **跟着已采用的线索与判断变化讲。** 交代当时知道什么、新信息出现后改变了什么。需要回溯时，用简短的时间、地点或人物提示把观众带回去。
3. **读起来像在讲故事。** 可以拆分长句、调整语序、用短句和停顿突出转折。人物称谓保持一致，指代可能混淆时直接说清是谁。难读的人名或术语可以给朗读版注明读法，字幕版保留采用写法。
4. **保留证据的边界和结尾回应。** 报案说法、调查判断、证言和裁判认定各有归属。已知先后与未确认的联系要在口播中说清。保持终稿的关键事实、必要细节和结尾回应。
5. **把值得看清的内容写进另外两列。** 比如两个时间要对照，就写明是哪两条记录、各要看清什么。具体用场景或图卡、怎样揭示，交给 05.2 和 05.3。
