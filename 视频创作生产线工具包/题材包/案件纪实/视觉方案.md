# 案件纪实视觉方案

05.2–05.3 读取画面表现与设计要求，06.2–06.4 按采用分镜读取素材制作与检查要求，08.1 在实际成片中检查落实情况。本期明确指定视觉方案时，按实际采用版本执行。

## 画面表现与设计要求

案件纪实的起始方案采用**克制的纪实漫画再现**，以人物动作、场所和关键物件帮助观众理解。真实照片、原始档案和公开资料按其性质另行呈现。AI 制作的再现场景使用清楚的「AI 情景再现」标识。

| 表达任务 | 建议画面 |
| --- | --- |
| 建立人物、时间和地点 | 有依据的场景插画、地图、时地标注。重复出现的人物与场所保持可辨认。 |
| 呈现已知行动或发现 | 用克制的再现场景交代任务、位置与动作。画面聚焦可核实的过程或必要情境。 |
| 解释时间、方位和证据联系 | 用时间线、方位图或全屏梳理卡，按旁白逐步揭示，保留阅读时间。 |
| 呈现原始材料 | 取得并适合使用的原始材料可标注来源后引用。为讲解制作的图示应注明其性质。 |
| 资料未披露或存在分歧 | 用有依据的局部、环境或图示交代已知范围，必要时由旁白明确限定。 |

场戏阶段记录人物、地点、时代和重要道具的共享设定。分镜写明画面类型、观众必须看见或读清的内容、卡面状态和依据。场景可以用与时代和场所一致的普通陈设帮助理解，承担关键事实的细节须有相应资料支持。

## 素材制作与检查

按镜号和用途制作素材，复用时核对本镜的裁切、可见信息和人物道具状态。图卡逐态检查文字、位置关系、观点归属和字幕避让。素材检查发现画面暗示了未经证实的动作、身份或结论时，回分镜确定采用有依据的呈现方式。

## 成片检查

核对观众能否在实际画幅和停留时间内辨认关键画面、读清图卡、跟上信息揭示。核对原始资料和再现画面能否区分，关键称谓、出处、时间和证据限定是否与采用稿一致。
