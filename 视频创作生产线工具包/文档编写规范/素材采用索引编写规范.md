# 素材采用索引编写规范

## 一、用途

06 按实际文件记录素材的用途、版本、来源和检查状态，供 07 按镜头调用，并供 08 回查。

## 二、内容与格式

在本期工程的 `06 配音与素材/` 保存 `素材采用索引.md`。同一素材用于多个不同镜头或卡面状态时，按实际用途列出或逐项注明。

```markdown
# 素材采用索引

- 本期选题：<已确认的选题>
- 采用的逐镜分镜：<实际路径及版本>
- 采用的视觉方案：<实际路径及版本>

| 素材编号与类型 | 镜号、用途或卡面状态 | 文件路径与版本 | 来源、制作依据及许可 | 检查状态及结果 |
| --- | --- | --- | --- | --- |
| <编号及素材类型> | <J 镜号、画面用途或图卡状态> | <实际相对路径及版本> | <来源与许可，或生成工具及制作依据> | <通过、待检查、退回或限次放行及实际结果> |

## 限次放行事项

<按需填写素材、版本、受影响的镜号或卡面状态、累计返修次数、剩余问题及影响。无则写「无」。>
```

## 三、表格列怎么写

| 列 | 填写要求 |
| --- | --- |
| 素材编号与类型 | 给实际制作或收集的素材一个可定位的编号，注明场景图、资料、图卡、配乐或音效等类型。 |
| 镜号、用途或卡面状态 | 用采用分镜的 J 镜号及用途定位。共用音频或跨镜图可注明适用范围。分步图卡标出状态。 |
| 文件路径与版本 | 指向本期实际交付或已登记复用的文件。换图、改字或调整用途后更新对应记录。需要防止调用错版时可补文件指纹。 |
| 来源、制作依据及许可 | 外部素材注明实际来源、适用许可和所需署名。生成素材记工具及可回查的提示词、参考或制作依据。 |
| 检查状态及结果 | 写清实际检查发现及结论。退回项记问题与复查，限次放行写明用途和剩余影响。 |

## 四、自查与交接

检查每个必需镜头或卡面状态能找到实际文件，路径、版本和使用范围与采用分镜一致。只将已通过或已登记限次放行的用途作为 07 的可用输入。限次放行文件用于候选合成，待决定项继续随候选交接。
