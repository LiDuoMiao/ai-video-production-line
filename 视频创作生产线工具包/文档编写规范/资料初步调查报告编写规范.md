# 资料初步调查报告编写规范

版本：V0.2 · 2026-11-13

## 一、用途

汇总 01.3 初查实际取得的资料内容和来源。01.5 在用户确认选题后整理并保存。03.1 用它了解已经掌握的背景与经过，03 的资料核对和补查也可以从其中的来源继续追查。

编写时使用 01.3 的初查结果和 01.4 用户最终确认的选题简介。最终采用哪些资料，以及哪些缺项需要补齐，由 03 对照故事框架处理。

## 二、内容与格式

文件名为 `资料初步调查报告.md`，保存在本期工程的 `01 启动阶段/` 中。按以下顺序填写，将模板中的占位内容换成本期实际内容。资料表每行记录一项可独立回查的内容。同一份资料提供多项信息时，可以分行，分别注明对应位置。

```markdown
# 资料初步调查报告

- 本期选题：<与《选题确认记录》一致>
- 题材：<与《选题确认记录》一致>

## 初查概况

<简述此次初查找到了哪些与讲述对象有关的主要资料。>

## 资料内容与来源

| 编号 | 资料内容 | 来源 | 定位与取得情况 |
| --- | --- | --- | --- |
| 1 | <实际取得的相关内容> | <资料名、发布者或作者，附链接或本地路径> | <页码、章节、时间码或相关位置，以及实际取得范围> |
```

## 三、字段和表格列怎么写

| 字段或列 | 填写要求 |
| --- | --- |
| 本期选题、题材 | 采用用户确认的名称，便于与《选题确认记录》配对。 |
| 初查概况 | 用几句话概括初查覆盖了哪些信息，例如人物、时间、地点、主要经过和已找到的来源类型。概况中的重要信息应能在下表回查。 |
| 编号 | 按表内顺序编号，方便后续讨论和引用。 |
| 资料内容 | 写清实际读到、听到或看到的相关内容。不同来源有分歧时，分别写出各来源的说法。 |
| 来源 | 写清文件、网页、书刊或音视频的名称，并提供实际可回查的链接或路径。已知作者或发布机构时一并注明。 |
| 定位与取得情况 | 按资料类型填写相关页码、章节、段落或时间码。只能取得摘要、部分页面或检索线索时，注明实际范围。仅找到线索的资料可以留作待追查来源，内容栏写明目前掌握的线索。 |

用户提供的资料如果已实际查看并用于初查，可以在表中列出，来源注明「用户提供」，并保留文件名或链接。

下面是一条虚构示例，用来说明如何区分已取得的内容和取得范围。

| 编号 | 资料内容 | 来源 | 定位与取得情况 |
| --- | --- | --- | --- |
| 1 | 目录摘要提到旧车站曾迁址，摘要中未写具体迁址年份。 | 《某地交通资料目录》，用户提供，见本期资料中的目录截图。 | 铁路条目，仅取得目录摘要。正文和迁址年份待追查。 |

## 四、自查与交接

| 检查什么 | 怎样判断达到要求 |
| --- | --- |
| 与选题一致 | 报告中的选题、题材和初查概况对应《选题确认记录》。用户纠正选题后，报告中的条目都与最终对象相关。 |
| 内容有出处 | 概况中的重要信息能找到对应的资料条目，每条实质资料能定位到原文件或链接及相关位置。 |
| 取得范围清楚 | 已读原文、只读摘要和待追查线索在表中有明确区分。不同来源的说法各有归属。 |
| 交接可用 | 03.1 能看出目前已掌握的背景与经过，03 的后续调查能直接沿报告中的来源追查。 |

核对完成后，将报告保存到本期作品，并核对《选题确认记录》中的报告链接指向实际文件。
