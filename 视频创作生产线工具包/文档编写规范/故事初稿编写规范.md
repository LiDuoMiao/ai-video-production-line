# 故事初稿编写规范

## 一、用途

04.1 根据 03 的方案、框架和最终调查报告写出从开头到结尾的完整故事，供 04.2 独立审稿。

## 二、内容与格式

在本期工程的 `04 故事创作/` 保存 `故事初稿.md`。按以下格式填写。

```markdown
# 故事初稿

- 本期选题：<已确认的选题>
- 采用依据：<故事讲述方案、故事框架、最终资料调查报告的实际路径>

## 故事正文

<从开头到结尾的完整故事，按需要分段>

## 依据与表达说明

- <需要审稿时回查的关键段落、资料位置和应保留的限制>
```

## 三、各部分怎么写

正文按采用的讲述顺序写完整经过，段落承担明确的推进任务。关键判断和引语须能回查依据。把对读者有影响的限制写进正文，将内部资料定位集中写在「依据与表达说明」中。写作篇幅随故事需要确定。

## 四、自查与交接

通读正文，核对切入点、推进与结尾能相互对应，事实与限定和 03 资料一致。保存实际送审稿并交给 04.2。后续修订写入终稿文件。
