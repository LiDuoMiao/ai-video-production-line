# 故事终稿编写规范

## 一、用途

04.3 保存原 AI 作家处理审稿意见后的采用稿，作为 05 编写口播稿的正文来源。

## 二、内容与格式

在本期工程的 `04 故事创作/` 保存 `故事终稿.md`。

```markdown
# 故事终稿

- 本期选题：<已确认的选题>
- 送审稿：[故事初稿](故事初稿.md)
- 审稿意见：[故事审稿意见](故事审稿意见.md)
- 采用依据：<最终故事框架和最终资料调查报告的实际路径>

## 故事正文

<修订并复核后的完整故事>

## 修订与交接说明

- <重要意见的实际处理，按需注明依据和保留的表达限制>
```

## 三、各部分怎么写

正文为本期采用的完整故事。修订说明简要记录重要意见的采纳、部分采纳或保留原写法的理由，注明需要下游继续沿用的事实限定、称谓或揭示顺序。正文无实质变化时写明与初稿一致。

## 四、自查与交接

核对修改涉及的事实、因果和前后衔接。切入点、主线或结尾有实质变化时通读全文。确认重要问题处理完毕、引用可定位后，将本文件交给 05 使用。
