# 最终资料调查报告编写规范

## 一、用途

03.3–03.5 用同一份报告草稿记录核对和补查。03.6 按最终《故事框架》整合初查与深查材料并定稿，供 04 写作和审稿。01 的《资料初步调查报告》继续保留原版。

## 二、内容与格式

在本期工程的 `03 故事方案/` 保存 `最终资料调查报告.md`。填写实际取得的材料。补查原件单独留存，在表中引用。

```markdown
# 最终资料调查报告

- 本期选题：<已确认的选题>
- 采用的框架：[故事框架](故事框架.md)
- 初查报告：[资料初步调查报告](../01%20启动阶段/资料初步调查报告.md)

## 可用资料

| 对应段落 | 资料内容 | 来源及定位 | 支持的讲述与限制 |
| --- | --- | --- | --- |
| <段号或段名> | <实际取得的相关信息> | <出处、链接或文件，以及页码、段落或时间码> | <能支撑的说法及需保留的限定> |

## 核对与补查记录

| 对应段落 | 核对结果或缺项 | 补查与复查结果 | 最终处理 |
| --- | --- | --- | --- |
| <段号或段名> | <已有依据或需要补的材料> | <实际补查取得的材料及复查结果> | <采用、保留限制或调整讲法> |

## 资料充足结论

<是否能支撑最终故事框架，以及仍需保留的限制>
```

## 三、表格列怎么写

| 列 | 填写要求 |
| --- | --- |
| 对应段落 | 引用《故事框架》的段号或段名，让写作者能定位到要用资料的段落。 |
| 资料内容 | 摘要实际取得的内容。存在多种说法时写清各自归属。 |
| 来源及定位 | 写明材料名称、发布者或作者、链接或文件及相关位置。只有摘要或转述时注明实际取得范围。 |
| 支持的讲述与限制 | 说明此材料能支撑哪个事实或判断，以及表达时要保留什么条件。 |
| 核对结果或缺项 | 写清逐段查到了什么、还缺什么。初查已够用时，可简记对应依据和核对结论。 |
| 补查与复查结果 | 写明补查结果及可回查的位置，并记录受影响段落的复查结论。 |
| 最终处理 | 写明如何采用，或资料仍不足时怎样保留未知、缩小表述或调整框架。 |

## 四、自查与交接

核对报告指向最终采用的框架。必要内容有可定位的依据，已知限制、分歧和调整结果明确。04 能直接用这份报告写作，并能按需回查来源。
