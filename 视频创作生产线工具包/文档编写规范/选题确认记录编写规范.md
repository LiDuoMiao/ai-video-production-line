# 选题确认记录编写规范

版本：V0.2 · 2026-11-13

## 一、用途

在 01.5 用户确认选题后，保存用户确认的是哪一个讲述对象，以及本期采用的题材和已有输入。02 用它识别本期制作任务，03.1 将它与《资料初步调查报告》一同用于生成讲述方案。

编写时使用 01.4 实际发送的最后一版选题介绍、用户确认回复和用户提供的起始资料。屏幕上的选题介绍按[启动阶段执行标准](../标准文档/01%20启动阶段执行标准.md#选题介绍固定格式)反馈。用户明确确认后，再按本规范保存正式记录。

## 二、内容与格式

文件名为 `选题确认记录.md`，保存在本期工程的 `01 启动阶段/` 中。以下四节按固定顺序填写，将模板中的占位内容换成本期实际内容。

```markdown
# 选题确认记录

## 选题与题材

- 本期选题：<已确认的选题名称>
- 题材：<本期采用的题材名称>
- 目标画幅：<横屏 16:9、竖屏 9:16 或横竖双版；注明用户要求或采用的默认值及出处>
- 成片分辨率：<宽×高像素，双版分别记录；注明出处>
- 采用的题材包：<本期实际采用的目录和版本>

## 已确认的选题简介

<用户最终确认的选题简介>

## 起始资料

- <用户提供的文件、链接或说明。没有则写「无」>
- 初查报告：[资料初步调查报告](资料初步调查报告.md)

## 确认结果

已确认
```

## 三、字段怎么写

| 字段 | 填写要求 |
| --- | --- |
| 本期选题 | 使用用户最终确认的名称。用户纠正过选题时，以纠正后确认的版本为准。 |
| 题材 | 使用本期实际采用的题材名称，供后续节点查找题材包。 |
| 目标画幅 | 保存 01 确定的实际值和出处，供 05–07 沿用。用户本期指定时按本期要求记录。 |
| 成片分辨率 | 记录成片宽×高像素及出处。横竖双版分别记录，核对各自与对应画幅一致。 |
| 采用的题材包 | 写明实际采用的目录。文件标有版本时记录版本。 |
| 已确认的选题简介 | 保存用户最终确认的那版简介。按用户确认的内容填写，保留已有的时间、地点、人物等识别信息。 |
| 起始资料 | 列出用户提供的文件、链接或说明。AI 初查所得内容与来源统一见《资料初步调查报告》。两份产物不在同一目录时，更新链接以指向实际文件。 |
| 确认结果 | 收到用户明确确认后写「已确认」。 |

## 四、自查与交接

| 检查什么 | 怎样判断达到要求 |
| --- | --- |
| 确认对象 | 记录中的选题、题材和简介与用户最后一次确认所对应的版本一致。 |
| 题材包 | 实际采用的目录可定位，版本信息与采用文件一致。 |
| 目标画幅与成片分辨率 | 已记录实际采用值及出处，05 能直接引用。 |
| 资料引用 | 用户提供的材料可找到，报告链接指向本期《资料初步调查报告》。AI 初查所得内容集中记录在该报告中。 |
| 交接可用 | 02 能据此识别本期制作任务，03.1 能用本记录和初查报告确定讲述对象并找到已有依据。 |

核对完成后，将本记录连同《资料初步调查报告》保存到本期作品。发现简介与用户确认有出入时，回查原确认消息并纠正记录。
