# 配音与语句时点记录编写规范

## 一、用途

06.1 记录实际配音及语句在交付音轨中的位置，供 07 统一搭建时间轴。

## 二、内容与格式

在本期工程的 `06 配音与素材/` 保存 `配音与语句时点记录.md`。

```markdown
# 配音与语句时点记录

- 本期选题：<已确认的选题>
- 采用的朗读版：<实际路径>
- 采用的配音音轨：<实际文件路径及版本>
- 配音工具、音色与参数：<实际采用值>
- 音轨时长：<实际文件的时长>
- 时点来源：<工具返回、实际音轨定位或其他已用方法>
- 核对范围与限制：<实际复听或核对范围、处理结果及尚未验证事项>

| 口播段号与语句 | 音轨时点 | 需特别留时或注意的事项 |
| --- | --- | --- |
| P01 · <用于定位的实际语句> | <相对交付音轨起点的起止时间> | <图卡阅读、观察或停顿提示，按需填写> |
```

## 三、字段和表格列怎么写

| 字段或列 | 填写要求 |
| --- | --- |
| 采用的朗读版与音轨 | 指向实际输入和实际输出，保证 07 读取的是同一组文件。 |
| 工具、参数和时长 | 按实际生成设置记录，时长以交付音轨为准。 |
| 核对范围与限制 | 记录实际做过的检查、发现的问题及修正结果。直接听审和技术核对分别说明。 |
| 口播段号与语句 | 沿用 P 段号，用实际短句定位分镜需要的声音节点。 |
| 音轨时点 | 使用统一格式，例如 `00:00:00.000`。根据实际音轨或随音轨取得的信息填写，尚未核实的时点明确标注。 |
| 特别留时或注意事项 | 提醒 07 哪个图卡、观察任务或关键停顿需要时间，按实际情况给出语句或镜号。 |

## 四、自查与交接

核对时点顺序、音轨范围和实际交付文件。重配、拼接或调速后，复查受影响时点。将本记录和音轨一同交 07，最终镜头与字幕时间写入制作时间轴。
