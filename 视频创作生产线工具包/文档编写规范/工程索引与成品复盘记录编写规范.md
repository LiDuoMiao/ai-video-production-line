# 工程索引与成品复盘记录编写规范

## 一、用途

《工程索引》让后续能找到正式成片及其对应的工程材料。《成品复盘记录》说明这一版为什么采用、改过什么，以及仍有哪些限制。两份文件保存在本期工程的 `09 成品复盘/`，通过实际路径引用已存在的记录和材料。

## 二、工程索引格式

保存为 `工程索引.md`。

```markdown
# 工程索引

- 本期选题：<已确认的选题>
- 正式成片及字幕：<实际路径及版本>
- 对应候选：<08 交接的实际文件>
- 成片规格：<画幅、宽×高、实际帧率与时长>

| 项目 | 采用文件或路径 | 用途 |
| --- | --- | --- |
| 故事、口播、场戏与分镜 | <实际采用文件> | <正文和设计依据> |
| 配音与素材 | <素材索引、实际音轨等> | <源文件和素材绑定> |
| 合成与时间轴 | <实际工程或脚本、时间轴、采用字幕及依赖说明> | <重做所需文件> |
| 检查与返修 | <08 检查记录及对应版本> | <采用结论与问题回查> |
```

## 三、成品复盘记录格式

保存为 `成品复盘记录.md`。

```markdown
# 成品复盘记录

- 本期选题：<已确认的选题>
- 正式采用版本：<实际成片路径及对应候选版本>
- 采用依据：<08 检查结论及相关记录>

## 检查与修订回顾

<简述实际检查范围、影响成片的改动和复查结果，引用对应记录。>

## 保留限制与本期复盘

<记录已知限制、实际反馈和本期可复用的经验。没有相应事项时注明。>
```

## 四、自查与交接

确认两份记录指向同一正式成片，工程索引中的路径可用。复盘中的检查和反馈按实际覆盖填写，引用 08 的结论。10 应能直接找到要交付的正式成片和字幕，并能追溯对应版本。
