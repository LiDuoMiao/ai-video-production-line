# 口播稿编写规范

## 一、用途

05.1 把《故事终稿》转成自然可读的旁白，并明确各段的场景必见项和理解任务，交给场戏设计、字幕与配音。

## 二、内容与格式

在本期工程的 `05 脚本分镜/` 保存 `口播稿.md`。采用下列三列，段号写在右列开头。

```markdown
# 口播稿

- 本期选题：<已确认的选题>
- 采用的故事终稿：[故事终稿](../04%20故事创作/故事终稿.md)

| 旁白主线 | 场景主要构成元素 | 深化与观众理解设计 |
| --- | --- | --- |
| <本段旁白正文> | <本段应呈现的人物、场所、行动、物件或图示> | **P01** · <观众要理解什么，哪些声画安排可以帮助理解> |
```

## 三、各列怎么写

| 列 | 填写要求 |
| --- | --- |
| 旁白主线 | 按终稿的顺序转成自然口语，完整承接原故事内容、因果、称谓和必要限定。静默或纯画面段可留空，并保留段号。 |
| 场景主要构成元素 | 写清事件进行到哪一步、谁在做什么、哪些细节必须可见，以及要认出还是读清。 |
| 深化与观众理解设计 | 指出观众需进一步理解或感受什么，以及适合怎样观察、比较或听见。具体机位和切点交给分镜。 |

从同一份采用旁白按段落顺序派生 `口播稿-字幕显示版.md` 和 `口播稿-配音朗读版.txt`。两版正文的内容与顺序一致。字幕版可保留仅用于显示的标记，朗读版只保留应读内容。纯画面段、段号和表内设计说明不送入配音正文。

## 四、自查与交接

通读旁白，核对终稿内容、限定与揭示顺序。按 P 段号核对另外两列是否能用于场戏设计。字幕与朗读版从同一稿重新核对，交给 06 使用。精确时间码在实际音轨生成后处理。
