# 08 检查与返修执行标准

## 一、用途与输入

检查 07 实际导出的完整候选片，修复可定位的问题，明确本期可交给 09 的版本和剩余事项。读取 `07 成片合成/` 中的候选片、合成与交接记录、实际时间轴和字幕。按问题回查采用的《故事终稿》《逐镜分镜》《素材采用索引》及 06 的听审待办。视觉检查按本期采用的[《视觉方案》](../题材包/案件纪实/视觉方案.md)执行，链接以案件纪实为例。

## 二、执行步骤

| 节点 | 动作与交接 |
| --- | --- |
| **08.1 检查实际成片** | 核对候选版本，按下方检查项查看实际文件，把结果和覆盖范围记入《成片检查与返修记录》。发现问题进入 08.2，检查已完成时记录结论。 |
| **08.2 定位问题并返修** | 按问题来源回对应环节修正，保留受影响的镜号、时点和版本。重新导出后回 08.1，复查受影响内容及相邻衔接。 |
| **08.3 记录检查结论** | 在同一份记录注明本期交接版本、已完成的检查和剩余事项。符合正式采用条件的版本交 09。仍有限次放行待决项时，交完整候选供查看并说明影响。 |

## 三、怎么检查

| 检查项 | 判断依据 |
| --- | --- |
| 技术与版本 | 确认实际候选文件与 07 交接版本一致。核对分辨率、时长、音视频流及完整解码。可引用同一文件的有效核对结果。 |
| 画面与运动 | 按镜头查看构图、必见项、跨镜连续性、再现标识和画面边缘。运镜重点看起落、停顿、抖动、闪烁和关键内容裁切。 |
| 图卡与字幕 | 按实际播放时点检查图卡揭示、留读和字幕避让。核对字幕与旁白、称谓和关键数字，涉及字幕时序改动时复查实际文件。 |
| 声音 | 实际听审时核对人名、数字、术语、语速、停顿、背景声与旁白平衡及音画同步。沿用 06、07 的待办，记录本次实际听到的范围。 |
| 叙事与事实 | 检查观众能否跟上线索、判断变化和结尾回应。核对实际旁白、画面和图卡是否遵守故事中的事实边界。 |

具备条件时，以正常速度连续看听实际候选。连续观看或直接听审受限时，尽量用逐镜帧序列、实际字幕和时间轴、可取得的音轨检查覆盖相关问题，并记录方法和范围。解码、抽帧、波形等分别记录为技术核对，用户反馈也单独注明实际覆盖。

## 四、返修与采用条件

- **已发现的错误**按原因回写作、分镜、素材或合成环节修正，再复查受影响内容。普通返修在已确认的制作范围内继续。
- **当前能做但尚未做的必要检查**先补做，再出结论。
- **完成可做检查后仍未验证的看听事项**记录范围和影响，按本期约定交接。
- **已达返修上限的素材**沿用限次记录。经修正通过或用户明确接受对应版本及用途后，才纳入正式采用。待决定时交候选并列明问题。

## 五、保存与交接

按[《成片检查与返修记录编写规范》](../文档编写规范/成片检查与返修记录编写规范.md)，在本期 `08 检查与返修/` 保存记录。需要返修并重导时保存新版候选。沿用 07 候选时直接引用实际路径及版本。只测试 08 时，在记录保存并核对后结束。
