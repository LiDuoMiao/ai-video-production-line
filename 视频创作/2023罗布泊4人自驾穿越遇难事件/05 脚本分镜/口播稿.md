# 口播稿

- 本期选题：2023 年罗布泊"4 人自驾穿越遇难"事件
- 采用的故事终稿：[故事终稿](../04%20故事创作/故事终稿.md)

| 旁白主线 | 场景主要构成元素 | 深化与观众理解设计 |
| --- | --- | --- |
| 2023 年 7 月 29 日，中午。罗布泊。地表温度接近七十摄氏度，沙面上看不见影子。 | 空旷的雅丹与沙丘，白到发亮的地平线，热浪扭曲空气。画面不出现人物。 | **P01** · 先建立极端环境：观众要感到这里"站着都难"，而不是风景。用长焦压平空间，让画面没有尽头。 |
| 受遇难者家属委托，救援者刘杰把车停下，往前走了几十米。沙里躺着一个人。他叫贾宁，是这次穿越的向导。 | 一台越野车停在沙地上，远处一个静止的人影。不拍面部细节。 | **P02** · 观众需立刻明白：这是一个已经结束的结果，故事从结局倒着讲。人物用远处剪影，避免猎奇。 |
| 他身上没有卫星电话，遗体还没有出现碳化。刘杰后来说，贾宁倒下的地方，就在他那辆陷住的皮卡，正东八公里。 | 沙漠中的皮卡轮廓（蓝色皮卡），方位示意线从中点向东延伸。 | **P03** · 观众要记住两个信息：八公里、正东。为此八公里这个数字在画面上单独出现一次，不靠字幕猜测。 |
| 再往前十二公里，是望舒村。往另一个方向，往雅丹地质公园走，是出这片沙漠最快的路。按刘杰的说法，两三个小时，就能出去。 | 俯视方位图：皮卡、遗体点、望舒村、雅丹地质公园与出口的相对位置。 | **P04** · 这是全片的"引信"：观众必须看清三个点之间的距离关系，否则后面所有数字都失去重量。方位图停留要够长，靠旁白配合逐步点亮。 |
| 两天前先被发现的三个人，倒在皮卡偏东南，七点八公里。两处遗体，相距三点二公里。 | 同一条方位线上出现第二组标记，两点之间标出三点二公里。 | **P05** · 让观众自己看出"他们是分两拨走的"，但此时不下结论。图卡只给位置与距离，不给原因。 |
| 六七十公里，正常三个小时。四个人，一个都没走出去。这段路，是在哪一步变成了绝路？ | 黑场收束，只留一行字与数字。 | **P06** · 抛出核心问题，把观众从结果拉回起点。此处留白一拍，情绪在静默里落下去。 |
| 回到七天前。7 月 22 日，一支车队从敦煌出发。 | 敦煌城郊清晨，车队集结、车顶行李、收尾的车灯。时间标"7 月 22 日"。 | **P07** · 观众需要一次明确的时间回溯信号，用出发车队的热闹与开头的寂静对照。 |
| 按随行队员李君讲，行程六月底就定了。向导贾宁联系了四川的越野爱好者，凑成九辆车、近二十人，组织方是四川一家改装车行。另有说法，九辆之外，还有两名向导各自带车。每人收费九千八百元，贾宁承诺提供全部物资。 | 车队车辆排列：陆巡、坦克、牧马人、霸王龙、皮卡；群像但不给具体人脸。 | **P08** · 让观众理解这是一次"有偿组织的商业行程"，这决定了后面的责任话题。收费数字要读清。 |
| 准备也不是没有。四台卫星电话、奥维 GPS、轮胎、牵引绳，部分车主还带了绞盘、气泵、千斤顶，每辆车大概四箱矿泉水。七天路线：库木塔格沙漠、彭加木失踪纪念地、小泉沟、飞机残骸，从花土沟方向出去。 | 后备厢整齐码放的矿泉水、装备摊开在地；路线地图按节点依次点亮。 | **P09** · 观众要和后文"车没坏、水没了"建立对照：这套装备看起来很齐。路线图要让七个节点一线串起。 |
| 另一个当时没被当回事的细节是：两台道奇公羊霸王龙，都没有装副油箱。 | 两台大型皮卡停在一起，油箱位置示意；画面淡出为沙漠。 | **P10** · 埋伏笔，语气要轻，不做预告式渲染。观众此时只需要"记住这件事"，不需要预判结局。 |
| 他们要穿过的，是若羌境内的罗布泊野骆驼国家级自然保护区。七点八万平方公里，极旱荒漠，野骆驼的栖息地，种群数量比大熊猫还少。 | 保护区边界示意与航拍式荒漠；野骆驼影像（可用公开图或插画，注明性质）。 | **P11** · 观众要明白这不是"无主荒地"，而是一块被划定的保护地。面积数字用对比表达（约等于几个城市的面积）。 |
| 这地方不是没主的荒地。2017 年以来，保护区管理局多次发布通告：严禁任何团体和个人进入旅游、探险，情节严重的，追究刑事责任。 | 公告牌、通告文本局部（可读几条关键句）、封禁的标识。 | **P12** · 观众要意识到"进不去"是规则，不是建议。通告能否用原文，取决于 06 阶段能取得的可用素材。 |
| 按事发时施行的《自然保护区条例》，核心区禁止任何人进入；未经批准进入保护区的，责令改正，可以罚款。 | 法条文本卡，只显示条目要点，不逐字堆满。 | **P13** · 只讲规则的作用，不背条文。避免让观众产生"轻罚所以无所谓的错觉"，语气要平。 |
| 罗布泊的夏天是另一层禁令。跑这条线的业内人说，六到九月根本不该进：地表能到七十度，沙子晒软，车一压就陷；人的需水量是平时的三四倍，三天的路，要备六到八天的水和油。 | 沙面特写，手指按下去留下坑；一张物资倍量对照示意。 | **P14** · 观众要理解"软沙"和"缺水"是这条路的两个物理条件，而非文学形容。特写加对比卡。 |
| 若羌县公安局后来的通报，给这趟行程的定性只有四个字：未经批准。 | 通报文本局部，红头与落款可读。 | **P15** · 把"违规"落回官方语言，为后段所有"为什么还去"的问题提供基准。 |
| 第二天起，车队开始频繁陷车。沙丘一座接一座，车反复陷沙，速度被拖慢。同时，两台没有副油箱的霸王龙，油表告警。贾宁把皮卡上的两桶储备油加给它们。按李君的回忆，加油后不到五分钟，两台车同时熄火。 | 沙丘中车辆反复陷沙、推沙板、绞盘牵引；加油动作特写；熄火后车灯灭、仪表暗。 | **P16** · 观众要抓住顺序：先缺油，再加油，加完立刻熄火。因果不能省，这是后面所有环节的起点。 |
| 到 7 月 24 日早上，出发才一个小时，又出了问题。车主们通过对讲机商量，怀疑油有问题，想把油箱加满，提高纯度。 | 对讲机通话的示意画面、几台车围着抛锚车辆。 | **P17** · 让观众体会到当时的判断方式：靠经验、靠商量，没有检测手段。 |
| 问题比想象中严重。按刘杰的说法和成都商报的报道，这一天大约两台霸王龙、一台陆巡，因为加了劣质油抛锚。其中一台霸王龙后来又加错柴油，清洗油箱的时候，不小心弄断了输油管。 | 三台车散落停下、车头朝向不一；油管断裂的物件特写。 | **P18** · 观众需要看清"三台车"和"三个动作"：加错柴油、清洗、断管。信息密度高，画面逐个对应。 |
| 霸王龙穿罗布泊毫无问题，但它要九十五号以上的汽油。参与救援的陈先生对封面新闻分析：向导按老经验备了九十二号，那批油的品质可能也有问题。 | 加油枪、油桶标签、汽油标号对照卡。 | **P19** · 观众要理解"不是车不行，是油不对"。标号常识用图卡解释，不靠观众自行知道。 |
| 三台车趴在沙漠里。队伍必须拆开。 | 沙丘间静止的车队，人物分散站立。 | **P20** · 一句转折，给下一段分组腾出空间。停顿。 |
| 分车，三条路。一台霸王龙的车主，跟着大部队继续往前走。一台陆巡，留在原地等救援。第三组，是那台坏掉的霸王龙上的两位游客，一男一女，加上随队的汽车修理工，由贾宁开着皮卡带出去。贾宁给他们指的方向，就是那条三小时的路。 | 俯视示意：一条线继续向北，一台车停下，一台皮卡向出口方向移动。 | **P21** · 这是全片的"分岔点"。观众必须看清三组人各有几个人、往哪走，后面的死亡数字才对得上。 |
| 就在这次撤离里，那台留在原地的陆巡，也就是后来报道里的广东牌照兰德酷路泽，也彻底开不动了。车上三个人。贾宁让他们在车里等，说自己很快派人来救他们。李君后来回忆：贾宁说好两个小时就回来接他们，但两天没有回来，也没有消息。 | 兰德酷路泽车头陷沙、车身向西；皮卡远去留下的车辙。 | **P22** · 观众要把"两个小时"这个承诺记住，它是后面等待与死亡的计时器。引语要有停顿，让承诺落在耳朵里。 |
| 从陷车点到雅丹地质公园方向，六七十公里，正常三个小时。贾宁的皮卡，没走完。它陷进了一个沙坑。 | 皮卡斜陷在沙坑中，车轮空转后停住；车辙到此为止。 | **P23** · 观众看到"三小时的路"第一次被截断。画面要给出"就差这么一点"的视觉感受。 |
| 事后救援的人看现场，结论出人意料：车没坏，只是陷在沙里开不动。空调是好的，油非常充足。唯一没有的，是饮用水。 | 车内视角：出风口、油表、空水桶。三个物件并置。 | **P24** · 全片最关键的反直觉事实。三个指标依次点亮：空调正常、油料充足、水为零，观众必须看清。 |
| 一台还能吹空调、油箱还满的车，停在离出口二三十公里的地方。按协助救援的刘先生的说法：如果车上的空调是正常的，那么他们在车里面，是没有任何问题的。 | 车与出口的远景关系，夕阳下静止的车身。 | **P25** · 让观众产生"如果不走，也许能活"的直觉，但先不给结论，留给下一句转折。 |
| 可他们下了车。 | 沙地上第一组脚印向远处延伸的特写。 | **P26** · 三个字，全片最重的一拍。画面只给脚印，不给理由。此处可留半秒静默。 |
| 刘杰根据脚印和遗体方位做了判断：贾宁和另外三个人不是一起走的。贾宁先徒步出去求援，三个人留在车上等；等了很久没有等到，他们也决定往外走。 | 两组脚印从车边分开：一条向东，一条向东南；时间感用光影变化示意。 | **P27** · 观众要明确这是"救援者根据痕迹的推测"，不是目击。措辞与画面都要保留推测属性。 |
| 从现场痕迹看，一行人是分两拨离开那辆车的。三个人往东南走了七点八公里，停下；贾宁往东走了八公里，停下。两个终点，相距三点二公里。 | 与 P05 相同的方位图复现，此时补上"分两拨"的路径线。 | **P28** · 与 P05 形成呼应：观众忽然明白开头那几个数字是怎么来的。图卡复用同一版式，只增加路径。 |
| 七月底的罗布泊，正午太阳直晒，气温四十多摄氏度，地表接近七十度。业内人士说，这种时候徒步求援不是最好的选择：即使不被渴死，太阳的暴晒也很快会让人昏厥倒下。 | 正午白光、地面热浪、踩在沙上的脚印边缘被光吞掉。 | **P29** · 让观众用身体感理解"走出去"意味着什么。用光影与质感，不用煽情配乐。 |
| 参与救援的陈先生说得更具体：他们开着车往外走，陷车以后，应该在车上开着空调原地等候救援，不应该徒步出去，因为当时罗布泊的温度太高了，那个太要命了。 | 救援者受访式构图的插画（标注为情景再现），车内空调出风与车外烈日对照。 | **P30** · 把专业判断落到具体做法上：这是可以照做的教训，不是抽象的感慨。 |
| 这是事后判断。当时在沙坑边的四个人，面对的是另一种算术：水已经不够撑到救援到来，救援不知道什么时候会来，而前面据说只有三个小时的路。 | 三个要素并置的图卡：剩余的水、未知的救援、三小时的路。 | **P31** · 观众要理解"选择"发生在信息不足里，而不是简单的判断失误。避免把当事人写成愚昧。 |
| 同一片沙漠里，另一组人做了不同的选择，拿到不同的结果。 | 画面转到另一台车（兰德酷路泽），沙丘另一侧。 | **P32** · 明确转场到对照组，让观众带着"如果是他们会怎样"的问题看下一段。 |
| 那台兰德酷路泽上的三个人，听贾宁的，在车里等。等了两天。他们放出无人机，有效可视范围正好十公里，找到了十公里外的"一号霸王龙"。 | 车内等待的三人、无人机升空的轨迹线、十公里外的车影。 | **P33** · 观众要记住"十公里"这个巧合性的距离条件：能看见，才可能走过去。 |
| 7 月 26 日早上，车临时打着，往那个方向挪了三公里，又熄火。两个人不带 GPS，凭无人机指的方向和记忆走过去，搬回 29 瓶矿泉水、两瓶啤酒，又捡石头在山坡上摆出"救命"两个字。回到车上接近中午十一点半，刚好躲过正午的暴晒。 | 车辆缓慢移动后熄火；两人徒步往返；石头上摆出的"救命"字样俯拍。 | **P34** · 观众看到"自救的另一种做法"：等、找、取、标记，每一步都是可辨认的行动。"救命"二字必须清晰可读。 |
| 他们还准备了更极端的手段：衣服拼成 SOS、浇上汽油点火、拆下备胎夜里点燃冒烟。都没用上。7 月 26 日，接应送油的保障车司机段明发，先看见了他们挥手。 | 备胎、汽油桶、拼成 SOS 的衣物（示意，不拍点燃）；远处驶来的保障车。 | **P35** · 不渲染未发生的极端行为，只说明他们准备了。画面停在"被看见"的那一刻。 |
| 7 月 27 日凌晨五点，补给车带着油开进沙漠；八点抵达霸王龙；上午十点，大部队全部驶出沙漠，找到信号，报警。当天 13 时许，若羌县公安局接到敦煌市公安局转警。 | 夜间车灯、沙丘剪影、时间轴依次点亮 05:00、08:00、10:00、13:00。 | **P36** · 观众需要一条清晰的时间轴：从出沙漠到报警之间的每一小时都在流失救援窗口。 |
| 7 月 27 日，搜救人员找到那辆陷沙的皮卡和三名遇难者。7 月 28 日，若羌县公安局通报：车队 22 日自敦煌出发，未经批准穿越若羌境内国家级野骆驼自然保护区，26 日 1 车 4 人失联；经搜救，27 日发现失联车辆，3 人已无生命体征，1 人失踪。7 月 29 日，最后一名失联者的遗体被找到。 | 通报全文版面，红头与落款清晰；日期在画面上依次出现。 | **P37** · 观众要看到"官方语言"与现场之间的距离：通报只有四行字，背后是四个人。通报原文可读，逐句跟随旁白。 |
| 问题回到最初。这三小时的路，为什么走不完。 | 回到开场的方位图，三个数字重新亮起。 | **P38** · 结构回扣，让观众意识到开头与结尾是同一个问题。画面与 P04 同版式。 |
| 中国探险协会在公开文章里列出的原因，是一串并列项：不遵守法律法规、未经批准非法穿越；没有周详的探险方案和应急救援预案；对目的地的地理、气候了解不足；装备物资准备不足；向导并非有资质的专业领队，无野外生存和救援能力，不熟悉卫星地图和 GPS，未配备合格的卫星电话；再加上沙漠驾驶技术不合格、陷车后处理不当。 | 逐条点亮的原因清单卡，一行一条，按旁白节奏出现。 | **P39** · 观众要看清"七项并列"而不是"一个主因"。清单按旁白逐条出现，全部出现后停留三秒再切。 |
